# SoccerShooter reference library archive

The complete reference library is split into nine GitHub-safe ZIP parts. Every part is below GitHub's 100 MB per-file limit.

Extract all nine ZIPs into the same folder to reconstruct the repository-relative paths:

1. Locked global and UI references
2. Locked arena references R001–R014
3. Locked arena references R015–R028
4. Locked camera and motion references
5. Locked athlete, team, equipment references
6. Locked pose, VFX, accessibility, and replay references
7. Working source files, first segment
8. Working source files, second segment
9. Metadata, rejects, golden manifest, and status documents

The original unsplit archive remains local for convenience but is intentionally not tracked because it exceeds GitHub's file-size limit.
